## 短文

**MCP Server が表示されない、または起動しない原因を MCPMender で調べられます。**

MCPMender は、Codex、Claude Desktop、Cursor、VS Code、Gemini CLI、
OpenCode で利用する MCP 設定を診断し、安全な修復を支援するローカル動作の
オープンソースツールです。

最初は MCP コマンドを起動せず、リモートエンドポイントにも接続しない
読み取り専用スキャンを実行します。必要な場合だけ実際の MCP ハンドシェイクを
確認でき、低リスクな修復候補は変更内容をプレビューしてから適用できます。
修復時にはバックアップとロールバック記録を作成します。Windows、macOS、
Linux 向けの Desktop と CLI があり、英語、簡体字中国語、日本語に対応します。

パブリックベータ：https://github.com/beyond5525/MCPMender

すべてのサーバーを修復できるわけではなく、サードパーティ製コードの安全性を
保証するものでもありません。ベータ版は OS の署名・信頼警告が表示される場合
があるため、実行前に公開されているチェックサムを確認してください。

## 長文

**オープンソース：MCP の設定診断と安全な修復を Desktop と CLI で行う
MCPMender**

MCP Server がクライアントに表示されない場合、見た目の症状が同じでも原因は
さまざまです。JSON や TOML の構文エラー、存在しない起動コマンド、未設定の
環境変数、無効な URL、認証失敗、タイムアウト、MCP ハンドシェイクの失敗など
が考えられます。

MCPMender は、設定ファイルをターミナルで手作業で調査することに慣れていない
ユーザーにも原因を分かりやすく示しつつ、スクリプトや自動化に使える CLI も
提供することを目標にしています。

現在のパブリックベータには次の機能があります。

- Desktop アプリケーションと `mcpmender` コマンドライン。
- Codex、Claude Desktop、Cursor、VS Code、Gemini CLI、OpenCode の MCP
  設定を検出。
- 設定されたコマンドを起動せず、リモート MCP エンドポイントにも接続しない
  読み取り専用の静的スキャン。
- 明示的な確認後に stdio または Streamable HTTP で実際の MCP initialize
  ハンドシェイクを行うライブ検査。
- 適用前に内容を確認できる決定的な低リスク修復。ファイルのバックアップ、
  外部変更の検出、ロールバック記録にも対応。
- ローカルでレポートを生成し、一般的な秘密情報をマスキング。
- アプリ、CLI、オフラインマニュアルで英語、簡体字中国語、日本語に対応。
- Windows、macOS、Linux 用ビルド。

自動修復は意図的に保守的に設計しています。プロバイダーのトークンを推測・
復元したり、任意の MCP Server を勝手にインストールしたり、サードパーティ製
コマンドが安全だと保証したりはしません。ライブ検査では設定されたコードの
実行やリモート接続が発生するため、実行前に境界を説明して確認を求めます。

現在のバージョンは 0.3.0-beta.4 で、安定版 1.0 ではありません。Windows 版は
自己署名証明書を使用する場合があり、macOS 版はアドホック署名で公証されて
いない場合があります。ダウンロードを実行する前にリリースノートを読み、
公開されている SHA-256 チェックサムを確認してください。
