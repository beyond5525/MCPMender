# MCPMender brand asset provenance

The MCPMender application mark was generated specifically for this project
with OpenAI's built-in image generation capability on 2026-07-29.

Prompt intent: two broken bridge/link segments securely rejoined by a cyan
repair clasp with a small amber craftsmanship spark. The prompt explicitly
excluded text, letters, pulse/heartbeat imagery, medical symbols, mascots, and
third-party brands.

- `mcpmender-icon-chroma.png`: original generated raster on a flat chroma-key
  background.
- `mcpmender-icon.png`: transparent project master produced with OpenAI's
  imagegen chroma-key removal helper.
- `../icons/`: derived platform icon sizes generated locally from the
  transparent master without third-party artwork.

These assets are distributed as part of MCPMender under the repository's
Apache-2.0 license. They do not contain or claim an external trademark.
